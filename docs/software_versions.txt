Software versions used in this study
====================================
Python:     3.12.13
Uni-Dock:   v1.1.3            (GPU-accelerated docking; Vina scoring function)
Open Babel: 3.1.0            (ligand/receptor preparation, format conversion, protonation)
ChimeraX:   1.12             (manual pose inspection)
RDKit:      2026.03.2        (3D embedding [ETKDG], MMFF94 minimization, descriptors, PAINS filter)

Notes
-----
- AlphaFold-Multimer (ColabFold) was used ONLY for a preliminary full-length feasibility check
  (interface ipTM ~0.19-0.21, judged unreliable); final docking did NOT use ColabFold-derived
  structures. Docking used the experimental complexes PDB 5EOF and 5EOA.
- If you cannot confirm the exact RDKit build in your own runtime, replace the RDKit line above
  and the corresponding manuscript Methods sentence with: "auxiliary descriptor calculations were
  performed where available using RDKit."
