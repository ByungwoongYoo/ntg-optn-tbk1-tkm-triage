# \(B_2[2]\) in \(\mathbb Z/100\mathbb Z\): 계산적 해결 보고서

## 결론

**조건을 만족하는 14개짜리 집합은 존재하지 않습니다. 최대 크기는 정확히 13입니다.**

13개짜리 실제 예시는 다음과 같습니다.

`[0, 5, 7, 31, 58, 61, 62, 63, 72, 80, 84, 91, 97]`

이 집합에 대해 0이 아닌 모든 순서차 \(a-b\pmod{100}\)의 출현 횟수를 다시 계산했으며, 최댓값은 **2**입니다. 따라서 13개는 실제로 가능합니다.

## 왜 14개를 전부 조사할 수 있었는가

14개짜리 후보 \(A\)에 100과 서로소인 차이가 하나도 없다고 가정합니다.

- 원소들이 모두 같은 짝홀성이라면 182개의 순서차가 49개의 0이 아닌 짝수 나머지에만 놓여야 합니다. 각 나머지는 최대 2회이므로 수용량은 \(49\times2=98\)뿐입니다.
- 짝수와 홀수가 모두 있다면, 서로 다른 짝홀 원소 사이의 차이는 mod 10에서 5여야 합니다. 그러면 사용 가능한 mod-10 잔여류는 \(r,r+5\) 두 개뿐이고 모든 차이가 5의 배수입니다. 0이 아닌 5의 배수는 19개이므로 수용량은 \(19\times2=38\)뿐입니다.

둘 다 필요한 \(14\times13=182\)에 못 미칩니다. 따라서 모든 14개짜리 후보에는 반드시 100과 서로소인 차이가 있습니다.

그 차이를 평행이동과 단위원 곱셈으로 1로 보내면, **일반성을 잃지 않고 \(\{0,1\}\subset A\)**로 둘 수 있습니다. 이 변환은 차이의 중복도를 그대로 보존합니다.

정렬한 집합을 \(0,1,t,\ldots\)로 쓰고 반사대칭을 적용하면 \(t=2,\ldots,45\)만 보면 충분합니다. 이 44개 경우를 모두 exact search로 완전탐색했습니다.

- \(t=2,3,4\): 네 번째·다섯 번째 원소로 다시 쪼갠 **255개**의 서로 겹치지 않는 하위 경우를 모두 완료했습니다.
- \(t=5,\ldots,45\): 나머지 **41개** 경우를 모두 완료했습니다.
- 완전탐색에서 14개짜리 증인은 **0개**였습니다.
- timeout을 비존재로 세지 않았습니다. 최종 표에는 완료된 경우만 포함했습니다.

따라서 14개는 불가능합니다. 위 13개짜리 예시가 있으므로 최대 크기는 정확히 13입니다.

## 독립·중복 확인

- 최소 원형 간격 \(g=2,3\)의 67개 정규화 경우도 별도 exact solver로 모두 완전배제했습니다.
- \(g=4,5,6,7\)은 CaDiCaL이 생성한 DRAT 증명서를 `drat-trim`이 각각 `VERIFIED`로 확인했습니다.
- \(t=10\)은 서로 다른 분할 실행에서 정확히 같은 node count `537,251,446`을 재현했습니다.
- 13개 witness는 별도 Python 계산으로 순서차 99개를 전부 다시 검사했습니다.
