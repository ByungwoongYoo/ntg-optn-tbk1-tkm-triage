# NEO-GUARD34 NEAT audit

This isolated branch runs an independent audit of the public NEAT repository pinned to commit `c1df534d90b08ee5d6e054d0797088067cbc4cd1`.

The workflow computes patient/row overlap, duplicate candidate identifiers, prospective three-class and patient-level metrics, patient-cluster bootstrap intervals, and an audit of whether model selection used patient-grouped resampling.

This branch is an audit workspace only. It does not change the `main` branch and makes no claim of clinical efficacy or autonomous decision support.
