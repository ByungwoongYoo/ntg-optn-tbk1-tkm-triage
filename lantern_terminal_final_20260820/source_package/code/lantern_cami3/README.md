# LANTERN — CAMI III

Longitudinal Assembly of Novel Taxa with Evidence-based Rescue and Non-leaky Validation.

This branch is an isolated computational workspace for the CAMI III Longitudinal Human Gut assembly challenge. It is not merged into the unrelated main project. Development uses the public CAMI III Toy Longitudinal Human Gut dataset and freezes all thresholds before any restricted challenge read is accessed.

## Claim boundary

A Toy-dataset improvement is method-development evidence only. It is not a CAMI III challenge result, a novel-organism discovery, or evidence of challenge rank. Actual challenge reads require acceptance of the CAMI data agreement by the human participant.
